# STEP 13 성능 검증 계획

## 로컬 기준선

앱·Worker 각 1개와 로컬 SQLite WAL DB를 사용한다. 프로세스·브라우저 버전과 실행 조건을 기록한 뒤 `GET /api/items` 및 `POST /api/items` 각 40건을 동시성 4에서 측정한다. 등록은 일반 독립 키와 별도로 같은 키를 사용한 동시 요청 10건도 검증한다. 정상 QA 3종을 한 번 큐에 넣어 시작·종료 시각과 작업 프로세스 메모리를 표본 추출한다.

| 지표 | 초기 확인 기준 |
| --- | --- |
| API 조회 및 등록 p95 | 각각 500 ms 미만 |
| SQLite 잠금 오류·동일 키 중복 저장 | 각각 0건 |
| 큐 대기 시간 | 유휴 Worker 단일 요청 5초 미만 |
| 정상 QA 3종 실행 시간 | 120초 미만 |
| Worker 메모리 | 작업 중 Worker 본체 메모리 최대 표본 기록. 브라우저·자식 프로세스는 별도 측정 대상 |

실제 값은 STEP 16 실행에서 기록한다. 기준 초과 항목은 요청 지연, DB 쓰기 경쟁, Worker 대기 또는 브라우저 I/O 구간으로 분해한다. 같은 장비와 부하 조건에서 재실행하여 변화 비교가 가능한 경우만 개선 결과로 보고한다.
