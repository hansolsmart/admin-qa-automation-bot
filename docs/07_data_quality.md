# STEP 07 데이터 품질

| 검증 | 판정 | 오류 처리 |
| --- | --- | --- |
| 완전성 | 선택된 ID별 판정 1개, 추가 판정 0개 | 결과 배치 전체 거절, 실행 `FAILED` |
| 도메인 | 고정 ID 및 `PASS/FAIL/ERROR/SKIPPED`; 정수 `duration_ms >= 0` | `INVALID_RESULTS` 기록 |
| 유일성 | `(run_id, scenario_id)` 중복 0건 | 제약 위반 시 종료·결과 일괄 롤백 |
| 파일 | 등록 가능한 파일은 지정 실행 디렉터리의 로그와 시나리오별 PNG | 누락은 링크 생략, 지정 경로 밖 파일은 거절 |
| 일관성 | 판정 건수와 집계 합계 일치, 만료 점유의 쓰기 거절 | 소유권 상실 시 쓰기 중단 |

앱 잠금에는 SQLite 대기 제한을 적용한다. 결과를 확보하지 못한 실행은 오류 코드와 가용 로그를 남긴다. 관리자가 새 실행을 만들어 재시도하며 기존 판정은 이력에서 유지한다. 테스트·증거는 합성 데이터만 사용하고 결과 메시지에 사용자 요청 본문을 넣지 않는다.
