## 충돌 및 중복 검토

- 등록 요청의 네트워크 재시도와 중복 제출은 같은 서버 멱등성 계약을 공유한다. 응답 유실과 동시 쓰기의 테스트 조건은 구분한다.
- 실행 상태 `FAILED`는 Worker 또는 실행 파이프라인 실패를 뜻한다. 테스트 자체에 `FAIL`이 있어도 선택 시나리오의 결과가 정상 수집되면 실행은 `COMPLETED`다.
- 관리자 입력은 원문을 보존하고, HTML 출력 지점에서 텍스트 처리한다. 이름의 공백만 입력, 허용 길이 초과 등 필드 제약은 저장 전에 검사한다.
- QA 실행의 이력·증거는 운영 DB와 보고서 저장소에 기록하며, 시나리오가 생성한 관리자 항목은 실행 전용 DB에 남는다.
- MVP 항목은 이름과 설명으로 구성한다. 데이터 삭제, 계정 관리 UI, 기본 시나리오 편집은 제품 범위에서 제외한다.
